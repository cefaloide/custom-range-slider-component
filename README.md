# Custom Range Slider

A custom `<Range />` component (built without `<input type="range">`). It is a dual-handle slider with two modes:

- **Normal**: continuous range between a `min` and a `max`, with a configurable `step` and editable labels.
- **Fixed**: handles can only be placed on a given set of values (`rangeValues`).

## Getting started

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```
